## 2.2. Установка Golang

### Способы установки:

1. Скачивание установщика пакета

   - Перейти на официальный сайт Go `https://go.dev/`
   - Нажать "Download" и выбрать версию в зависимости от операционной системы:
     `Windows`: выбрать указанный пакет для Windows.
     `Mac с процессорами M1 и выше`: выбрать архив для архитектуры ARM.
     `Mac с более старой архитектурой`: выбрать соответствующий пакет.
     `Linux`: выбрать версию для Linux.
   - Запустить установщик и следовать инструкциям.

Переключение версий Go (стандартный без установки менеджеров пакетов)

```shell
go install # (для управления версиями без WSL)
```

Способ установки нескольких версий:

```shell powershell
# Установка Go 1.21.0
go install golang.org/dl/go1.21.0@latest
go1.21.0 download
```

Плюсы:
✅ Официальный метод, не требует менеджеров.
✅ Можно иметь несколько версий.

Минусы:
❌ Нужно вручную вызывать go1.21.0 вместо go.
❌ Нет автоматического переключения.

Подходит, если:
🔹 Не хотите ставить Chocolatey/Scoop.
🔹 Готовы управлять версиями вручную.

2. Использование пакетного менеджера (Homebrew для macOS и Linux, Choco для Windows)

- Преимущество: удобное обновление.
- Homebrew устанавливается через терминал с помощью одного скрипта.
- Установка Go: `brew install go`.

3. Менеджеры версий `asdf-vm.com` или `goenv`

goenv и asdf это два популярных менеджера управления пакетами, самый популярный goenv.
На Windows нужно использовать WSL, нет нативного варианта.
WSL + goenv/asdf если вы используете WSL2:

Пример установки goenv:

```bash
# Установка goenv (специально для Go)
git clone https://github.com/syndbg/goenv.git ~/.goenv
echo 'export GOENV_ROOT="$HOME/.goenv"' >> ~/.bashrc
echo 'export PATH="$GOENV_ROOT/bin:$PATH"' >> ~/.bashrc
echo 'eval "$(goenv init -)"' >> ~/.bashrc
source ~/.bashrc

# Установка Go
goenv install 1.21.0
goenv global 1.21.0
```

Плюсы:
✅ Полная поддержка версий (как в Linux).
✅ Автоматическое переключение в проектах.

Минусы:
❌ Требует WSL (не чистая Windows).

Подходит, если:
🔹 Вы работаете с WSL (например, для Docker, Kubernetes).
🔹 Нужны сложные сценарии с разными версиями Go.

4. Chocolatey (Choco) — Windows

```shell powershell
choco install golang
```

Плюсы:
✅ Быстрая установка одной командой.
✅ Легко обновлять (choco upgrade golang).
✅ Можно установить конкретную версию (через -version).

Минусы:
❌ Нет удобного переключения между версиями (как в goenv/asdf).
❌ Зависит от Chocolatey (не всем нравится).

5. Scoop — альтернатива Chocolatey с поддержкой версий

```shell powershell
scoop install go
# Или конкретная версия
scoop install go@1.21.0
scoop reset go@1.21.0  # Переключение
```

Плюсы:
✅ Легко переключать версии (`scoop reset go@версия`).
✅ Не требует админ-прав (устанавливает в `~/scoop`).

Минусы:
❌ Меньше версий, чем в `goenv/asdf`.

Подходит, если:
🔹 Хотите что-то проще Chocolatey.
🔹 Нужно переключать версии, но без WSL.

## 2.3. Установка Scoop на Windows

Scoop — менеджер пакетов для Windows, который устанавливает программы без прав администратора (в папку пользователя).

1. Предварительные требования
   Windows 10/11 (или Windows 7+ с PowerShell 5.1+).

PowerShell 5+ (проверьте версию):

```shell powershell
$PSVersionTable.PSVersion
```

Если версия ниже 5.0, обновите PowerShell.

2. Установка Scoop

🔹 1. Откройте PowerShell (от имени пользователя, не админа!)
Нажмите Win + X → Windows PowerShell (или Terminal).

🔹 2. Разрешите выполнение скриптов

```shell powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

(Ответьте Y на запрос).

🔹 3. Установите Scoop

```shell powershell
irm get.scoop.sh | iex
```

🔹 4. Проверьте установку

```shell powershell
scoop --version
```

Должна отобразиться версия (например, 7.3.2).

3. Настройка Scoop (опционально)

🔸 Добавление репозиториев (бакетов)
Scoop использует "бакеты" (коллекции пакетов). Основные:

```shell powershell
scoop bucket add main      # Основные программы (по умолчанию)
scoop bucket add extras    # Доп. ПО (например, Notepad++)
scoop bucket add versions  # Версионные пакеты (Node.js, Go и др.)
```

🔸 Обновление Scoop

```shell powershell
scoop update
```

4. Установка Go через Scoop

```shell powershell
scoop install go           # Последняя версия
# Или конкретная версия:
scoop install go@1.21.0
scoop reset go@1.21.0      # Переключение версий
```

## 3.1. Создание первого приложения

Cоздание и запуск базовых приложений на языке программирования Go.

### Настройка среды разработки:

Открыть папку проекта в Visual Studio Code. Это можно сделать, перетащив папку в окно редактора, или используя команду `code .` в терминале, предварительно перейдя в директорию проекта (`cd go-abc`).

### Создание основного файла:

1. В корневой директории проекта создается файл `main.go`.
2. В файле `main.go` указывается имя пакета как `package main`.
3. Определяется функция `main` внутри файла. Она будет точкой входа приложения.

### Программирование функционала:

Для вывода текста используется пакет `fmt` и его функция `Println("Привет")` или `Printf("Привет")` внутри функции `main`:

```Go
// Объявление наименования пакета
package main

import "fmt"

// Entry function - Функция входа - функция, запускающая приложение
func main() {
	fmt.Printf("Привет")
}
```

### Запуск приложения:

Запуск приложения в терминале

```shell
go run main.go
```

Результат выполнения команды: в терминале отобразится сообщение "Привет"

## 3.2. Packages

Цель пакетов в Go: Обеспечение модульности приложений путем декомпозиции логики на набор пакетов. Это улучшает поддержку кода, делает его переиспользуемым и инкапсулирует логику.

Преимущества: Помогают в структурировании кода, обеспечивают его модульность, позволяют переиспользовать код и инкапсулировать функционал.

### Виды пакетов

1. `Собственные пакеты`:
   Пакеты, созданные разработчиком для специфических нужд приложения (например, сервисы, репозитории).

2. `Main пакет`:
   Точка входа в приложение Go, без которой выполнение программы невозможно. Каждый файл Go должен начинаться с объявления пакета.

3. `Стандартные пакеты`:
   Библиотека пакетов, предоставляемая Go, охватывает широкий спектр функционала (работа с OS, сетью, логами, форматирование вывода и др.).

   https://pkg.go.dev/std

4. `Внешние пакеты`:
   Пакеты, используемые из внешних источников для расширения функционала приложения, например, пакеты для работы с MIME типами.

### Импорт и использование пакетов

1. Пакеты в Go импортируются с помощью ключевого слова `import`, после чего функционал пакета может быть использован в коде.

2. Создание собственных пакетов требует объявления пакета в начале файла и предоставляет возможность инкапсулировать логику работы с определенной функциональностью.

### Точка входа и выполнение приложения

1. В пакете `main` должна быть определена функция `main`, которая служит точкой входа в приложение.

2. В коде можно использовать функции из стандартных и внешних пакетов для реализации функционала приложения.

## 3.3. Go modules

### Пакеты vs. Модули:

Пакеты формируют модульность системы, но они не являются модулями. Модуль может представлять собой целое приложение, содержащее различные пакеты.

Пример: `app` модуль может содержать пакет `main`, `пакет 1`, `пакет 2` и `внешнюю зависимость`, каждая из которых упрощает управление структурой приложения.

### Инициализация Модуля

1. Необходимость Инициализации:
   Для успешной компиляции приложения необходимо инициализировать модуль, поскольку только наличие пакета `main` недостаточно.
2. Процесс Инициализации:
   Используя команду `go mod init <имя приложения>`, можно инициализировать модуль, где `<имя приложения>` либо путь для публичной публикации (например, на GitHub), либо локальное наименование для личного использования.
3. Файл `go.mod`:
   После инициализации модуля создается файл `go.mod`, который содержит наименование модуля и версию `Go`, с которой совместим модуль.

```shell
go mod init demo/app-1
```

Результат

```Text
go: creating new go.mod: module demo/app-1
go: to add module requirements and sums:
        go mod tidy
```

Файл, сгенерированный при инициализации приложения `go.mod`:
В дальнейшем можно вручную переименовать `demo/app-1`, например, если возникнет необходимось опубликовать приложение.

```
module demo/app-1

go 1.24.3
```

При именовании модуля могут использоваться латинские символы и символ `/`, например: `test/api`.
Для публикации приложения на GitHub это может быть строка URL как у репозитория, например: `github.com/biouri/go-abc`.

Импорт в коде → должен совпадать с URL репозитория

```go
import "github.com/user/go-abc"
```

Структура проекта (если это библиотека + CLI):

```Text
.
├── cmd/          # Исполняемые приложения (если есть)
│   └── myapp/    # main-пакет
│       └── main.go
├── pkg/          # Код библиотеки (опционально)
│   └── mylib/
├── go.mod        # Модуль Go
└── README.md
```

#### Основные правила именования:

1. Короткое, понятное, описательное имя (например, scanner, calculator, jsonparser).
2. Используйте lowercase без пробелов и спецсимволов (разделитель — дефис `-` или подчёркивание `_` допускается, но не рекомендуется).
3. Избегайте общих названий (utils, helpers, common — слишком абстрактно).
4. Для публичных библиотек — уникальное имя (можно проверить на `pkg.go.dev`).

### Сборка Приложения

#### Команда `go build`:

После инициализации модуля можно использовать команду `go build` для компиляции приложения в исполняемый файл (бинарник).

```
go build
```

#### Преимущества Go:

В отличие от других языков, Go позволяет компилировать приложение вместе с необходимым `runtime` в один бинарник, делая его портативным и независимым от наличия Go на конечной системе.

#### Исполнение Приложения:

Собранный бинарник может быть запущен на любой операционной системы без установленного Go, обеспечивая удобство распространения.

### Управление Версиями

Файл `.gitignore`: Рекомендуется исключать собранные бинарники из репозитория с помощью `.gitignore`, сохраняя в контроле версии только файл `go.mod`, зависимости и исходный код программы.

## 3.4. Переменные и значения

Переменные и типизация в языке программирования Go.

### Что такое переменная?

Контейнер для хранения данных.
Имеет тип, который определяет характер хранимых данных.

### Почему важны типы переменных?

Go — строго типизированный язык, требует точного определения типа данных.
Типы данных влияют на операции, которые можно выполнять с переменными.

В Go нельзя оставлять в коде неиспользуемые переменные или импорты других пакетов.

### Пример проекта: Калькулятор ИМТ

Калькулятор индекса массы тела (ИМТ):

- Формула ИМТ: `Вес (кг) / (Рост (м)^2)`.
- Диапазоны ИМТ: <16 - дефицит массы, 18-25 - норма, >25 - различные степени ожирения.

Шаги реализации:

1. Определение переменных:
   Создание переменных для веса и роста пользователя.
   В Go используется `var` для объявления переменных.
   Имена переменных следуют правилам `lowerCamelCase` (например, `userHeight`).

2. Типы данных: Автоматическое присвоение типов данным (например, `float64` для роста).
3. Операции с переменными: Расчёт ИМТ с учётом строгой типизации.
   Важное отличие Go от некоторых других языков в строгости работы с типами данных.

### Проблемы типизации:

- Попытка выполнить операцию с переменными разных типов приводит к ошибке.
- Необходимо понимание типов данных и правил их взаимодействия.

```Go
// Объявление наименования пакета
package main

import "fmt"

// Entry function - Функция входа - функция, запускающая приложение
func main() {
	var userHeight = 1.76 // атоматически выводится тип переменной float64
	var userKg = 68       // атоматически выводится тип переменной int
	var IMT = float64(userKg) / (userHeight * userHeight) // приведение к типу float64

	fmt.Printf("Индекс массы тела (ИМТ): %.2f", IMT)
}
```

## 3.5. Типы

1. Причины типовых ошибок:

   Ошибки при работе с различными типами данных (`int` и `float64`) и почему в Go, в отличие от некоторых других языков программирования, такие операции не допускаются из-за статической типизации.

2. Типы данных `int` и `float64`:

   - `int` - представляет целые числа.
   - `float64` - представляет числа с плавающей точкой.

3. Выведение типов:

   - Как Go автоматически определяет тип переменной на основе присвоенного ей значения и как это влияет на работу с переменными разных типов.

4. Решение типовых ошибок:

   - Явное указание типа данных: Как избежать ошибок, явно указывая тип переменной:

   ```Go
   var userKg float64 = 68
   ```

   - Явная конвертация типов: Как использовать функцию конвертации для преобразования одного типа данных в другой:

   ```Go
   var a = float64(userKg)
   ```

5. Работа с математическими операциями:

   - Пакет `Math` для выполнения операций возведения в степень.
   - Метод `Pow` для возведения числа в степень и его использование на практике.

6. Пример расчёта индекса массы тела (ИМТ):

   Расчёт ИМТ, включая объявление переменных с явным указанием типа, конвертацию типов и использование математических функций.

```Go
// Объявление наименования пакета
package main

// Импорт нескольких пакетов
import (
	"fmt"
	"math"
)

// Entry function - Функция входа - функция, запускающая приложение
func main() {
	var userHeight = 1.76 // атоматически выводится тип переменной float64
	var userKg = 68       // атоматически выводится тип переменной int
	// var userKg float64 = 68 // Тип можно указать после имени переменной
	// Обернуть во встроенную функцию float64(...) для конвертации типа
	var IMT = float64(userKg) / math.Pow(userHeight, 2) // Возведение в степень

	// Print с форматированием
	fmt.Printf("Индекс массы тела (ИМТ): %.2f", IMT)
}
```

## 3.6. Варианты записи переменных

Различные способы объявления переменных в языке Go.

### Основные Способы Объявления Переменных:

1. Использование var:
   - Применяется, когда необходимо явно указать тип переменной.
   - Используется, если переменной сразу не присваивается значение.

Пример:

```go
var userHeight float64
```

2. Короткая запись без `var` - `:=`:
   - Позволяет опустить `var` и тип, автоматически выводя тип из присваиваемого значения.
   - Не позволяет явно указать тип (тип выводится автоматически).
   - Применяется для упрощения и ускорения написания кода.

Пример:

```go
userHate := 1.8
```

3. Объявление нескольких переменных:

   - Можно объявить несколько переменных в одной строке, разделяя их запятыми.
   - Этот метод удобен для объявления нескольких связанных переменных, но может ухудшить читаемость при большом количестве переменных.
   - Все переменные в таком объявлении должны иметь один тип.

Пример:

```go
var userHeight, userWeight float64
```

### Рекомендации по выбору способа объявления:

- Используйте `var` для явного указания типа или когда переменная изначально не инициализирована.
- Короткая запись `:=` предпочтительна для локальных переменных с немедленным присваиванием.
- Для объявления нескольких связанных переменных удобно использовать объявление через запятую, особенно если тип одинаков.

Пример в коде:

Использование короткой записи для объявления и инициализации переменной с выводом её типа и значения:

```Go
amt := 30.0 // переменная с типом float64
fmt.Println(amt) // вывод значение переменной
```

Общий принцип заключается в выборе метода, который максимально упрощает код и делает его легко читаемым, при этом не теряя контроль над типами данных и инициализацией переменных.

```Go
// ...
func main() {
	userHeight := 1.76 // атоматически выводится тип переменной float64
	userKg := 68       // атоматически выводится тип переменной int
	// var userKg float64 = 68 // Тип можно указать после имени переменной
	// Обернуть во встроенную функцию float64(...) для конвертации типа
	IMT := float64(userKg) / math.Pow(userHeight, 2) // Возведение в степень
   // ...
}
```

## 3.7. Константы

Константы используются для значений, которые не должны изменяться во время выполнения программы. Это может включать числовые литералы, строки (например, сообщения об ошибках) и другие значения, которые должны оставаться постоянными.

### Константы vs. Переменные:

Константы позволяют задать значение один раз, которое не изменяется во время работы программы, в отличие от переменных, которые могут менять своё значение.

### Объявление констант:

Для объявления констант используется ключевое слово `const`, например, `const IMT_POWER = 2`.

### Примеры и особенности

1. Использование:
   Константы идеально подходят для задания неизменяемых значений, таких как числовые литералы, которые можно использовать в качестве параметров или "магических чисел" в вычислениях.

2. Ограничения:
   Попытка переопределить значение константы вызовет ошибку, поскольку Go рассматривает константы как неизменяемые значения.

3. Typed vs. Untyped Constants:

   - Untyped Constants: Могут быть использованы без указания конкретного типа, что позволяет Go автоматически определять тип в зависимости от контекста использования. Например, untyped константа с числовым значением может быть использована в вычислениях как `int`, так и `float64`.

   - Typed Constants: Для них явно указывается тип, что делает их использование более строго типизированным.

### Практическое применение

```Go
// Объявление наименования пакета
package main

// Импорт нескольких пакетов
import (
	"fmt"
	"math"
)

// Entry function - Функция входа - функция, запускающая приложение
func main() {
	const IMTPower = 2 // Константа для возведения в степень

	// := сокращенная запись создания переменных как альтернатива var
	userHeight := 1.76 // атоматически выводится тип переменной float64
	userKg := 68       // атоматически выводится тип переменной int
	// var userKg float64 = 68 // Тип можно указать после имени переменной
	// Обернуть во встроенную функцию float64(...) для конвертации типа
	IMT := float64(userKg) / math.Pow(userHeight, IMTPower) // Возведение в степень

	// Print с форматированием
	fmt.Printf("Индекс массы тела (ИМТ): %.2f", IMT)
}
```

```Go
	"fmt"

	IMT := userKg / math.Pow(userHeight, IMTPower) // Возведение в степень

	// Print с форматированием
	fmt.Printf("Ваш индекс массы тела (ИМТ): %.2f", IMT)
}
```

### Нулевые значения (zero values)

Каждый тип в Go имеет своё "нулевое значение", которое переменная получает при объявлении без инициализации:

```Text
Тип         Нулевое значение
int         0
float64     0.0
bool        false
string      "" (пустая строка)
Указатели   nil
Срезы       nil
Мапы        nil
Каналы      nil
Интерфейсы  nil
Функции     nil
```

```go
var i int       // 0
```

### Отличия от JavaScript

В Go нет аналогов `undefined` и `null` в js-стиле
Вместо null используется nil, но только для:

- указателей
- срезов
- мап
- каналов
- интерфейсов
- функций

## 4.2. Форматирование строк

Обычно используется функция `Print` для вывода значений.

Функция `Println`:
`Println` печатает строку без добавления лишнего символа переноса строки, делая код аккуратнее.

Функция `Printf`:
Позволяет форматировать строку с заменой спецификаторов требуемыми значениями переменных.
Спецификатор `%v` используется для вставки значения переменной как есть.
Пример: `fmt.Printf("Ваш индекс: %v", переменная)`.

Форматирование чисел с плавающей точкой:
`%f` используется для форматирования чисел с плавающей точкой.
Можно указать количество знаков после запятой, например `%.2f` для двух знаков.

Практическое Применение:
Преобразование высоты из метров в сантиметры перед выводом, для более удобного представления.

Пример: вместо ввода 1.81 метра, вводим 181 см.

### Функция Printf в Go (пакет fmt)

`Printf` форматирует и выводит текст согласно шаблону формата.
Отличается от `Println` тем, что не добавляет пробелы/переносы строк автоматически.

Синтаксис

```go
fmt.Printf("Шаблон %формат", аргументы)
```

Основные спецификаторы формата

```Text
Спецификатор  Тип                       Пример вывода
-----------------------------------------------------
%v            Универсальный             42, hello
%d            Целое число               256
%f            Число с плавающей точкой  3.14
%g	           %f или %e (автовыбор)     3.1415926535
%e            Научная нотация           1.23e+08
%s            Строка                    Привет
%t            Булево значение           true
%p	           Указатель (адрес)         0xc0000180b0
%T            Тип переменной            int, string
%%            Символ %                  %
```

### Примеры форматирования

1. Числа

```go
num := 42
pi := 3.1415926535

fmt.Printf("%d в HEX: %x\n", num, num)  // 42 в HEX: 2a
fmt.Printf("PI: %.2f\n", pi)            // PI: 3.14 (округление)
fmt.Printf("Научный: %e\n", pi*1000)    // Научный: 3.141593e+03
```

В Go для вывода целого числа (`int`) с обязательным указанием знака (даже для положительных чисел) используется спецификатор формата:

`%+d` добавляет знак `+` перед положительными числами и `-` перед отрицательными.

Примеры:

```go
package main

import "fmt"

func main() {
    positive := 42
    negative := -42
    zero := 0

    fmt.Printf("Со знаком: %+d\n", positive)  // Вывод: +42
    fmt.Printf("Со знаком: %+d\n", negative)  // Вывод: -42
    fmt.Printf("Со знаком: %+d\n", zero)      // Вывод: +0
}
```

Другие варианты форматирования чисел:

```Text
-------------------------------------------------------
Спецификатор  Результат  Результат  Описание
              для 42     для -42
-------------------------------------------------------
%d            42         -42        Без знака для +
%+d           +42        -42        Принудительный знак
%5d           42         -42        Ширина 5 символов
%05d          00042      -0042      Дополнение нулями
-------------------------------------------------------
```

Особенности:

- Для шестнадцатеричных чисел (`%x`) и других систем счисления знак `+` не работает.
- Для вещественных чисел (`%f`, `%g`) также можно использовать `%+f`:

```go
fmt.Printf("%+f", 3.14)  // +3.140000
```

Когда использовать:

- Логирование значений с явным указанием знака.
- Вывод данных, где важны визуально положительные и отрицательные значения (например, финансовые операции).

2. Строки

```go
name := "Alice"

fmt.Printf("Имя: %s\n", name)       // Имя: Alice
fmt.Printf("7 символов: %7s\n", name)  // "  Alice" (дополнение пробелами)
fmt.Printf("Квотировка: %q\n", name)   // "Alice" (в кавычках)
```

3. Структуры

```go
type User struct {
    Name string
    Age  int
}

u := User{"Bob", 30}

fmt.Printf("%v\n", u)   // {Bob 30} (просто значения)
fmt.Printf("%+v\n", u)  // {Name:Bob Age:30} (с именами полей)
fmt.Printf("%#v\n", u)  // main.User{Name:"Bob", Age:30} (полное описание)
```

4. Ширина и точность

```go
n := 123.456

fmt.Printf("|%8.2f|\n", n)   // |  123.46| (8 символов, 2 знака после запятой)
fmt.Printf("|%-8.2f|\n", n)  // |123.46  | (выравнивание влево)
```

5. Булевы значения

```go
fmt.Printf("%t\n", 10 > 5)  // true
```

6. Указатели и типы

```go
x := 10
fmt.Printf("Тип: %T, Адрес: %p\n", x, &x)
// Тип: int, Адрес: 0xc0000180b0
```

### Полезные фишки

Индекс аргументов (порядок вывода):

```go
fmt.Printf("%[2]d %[1]d\n", 10, 20)  // "20 10"
```

Дополнение нулями:

```go
fmt.Printf("ID: %04d\n", 42)  // ID: 0042
```

Шестнадцатеричный вывод:

```go
fmt.Printf("%x\n", "hello")  // 68656c6c6f (байты в HEX)
```

### Отличие от других функций fmt

```Text
Функция  Автоперенос  Форматирование   Пример
------------------------------------------------------------
Print        Нет            Нет        Print(1, 2) → 1 2
Println      Да             Нет        Println(1, 2) → 1 2\n
Printf       Нет            Да         Printf("%d", 1) → 1
```

- Необходимо ручное управление отступами внутри мультистрочных строк.
- Можно использовать функцию `printf` для добавления форматирования и переменных в мультистрочные строки.

### Использование Мультистрочных Строк

- Мультистрочные строки полезны для хранения длинного текста в коде без необходимости использования конкатенации.

### Особенности

## 4.5. Создание функции

Функция – это блок кода, выполнение которого начинается при его вызове. Они используются для выполнения определенной задачи и могут быть переиспользованы в различных частях приложения. Функция main – особый случай, запускающий приложение.

### Зачем нужны функции

1. Для избежания дублирования кода: функции позволяют использовать один и тот же код в различных местах программы без необходимости его повторения.
2. Для разделения логики: помогают структурировать код, выделяя отдельные логические части.

### Как создать функцию

- Используется ключевое слово `func`, за которым следует название функции, параметры (в скобках) и тело функции (в фигурных скобках).
- Название функции должно отражать её действие.
- Параметры функции задаются с указанием их типа.
- В теле функции размещается код, который будет выполнен при ее вызове.

### Пример:

Создание функции `outputResult` для вывода результатов:

```Go
func outputResult(imt float64) {
	// Тело функции
	// Sprintf - создание строки с форматированием
	result := fmt.Sprintf("Ваш индекс массы тела (ИМТ): %.2f", imt)
	fmt.Print(result)
}
```

В данном примере `amt` является аргументом функции, представляющим индекс массы тела типа `float64`.

### Вызов функции:

Функция вызывается по имени с передачей необходимых аргументов.
Пример (вызов функции `outputResult` с аргументом `25.0`):

```Go
outputResult(25.0)
```

## 4.6. Возвращаемое значение

### Пример функции CalculateAMT:

Назначение: функция для расчёта AMT
`Параметры`: принимает два значения типа `float64` (вес в килограммах и рост в сантиметрах).
`Возврат значения`: функция возвращает результат расчёта типа `float64`.

### Типизация в Go:

Язык Go требует явного указания типов данных, включая тип возвращаемого значения функцией.

Возвращение результата: использование ключевого слова `return` для возврата итогового значения расчёта из функции.

## Пример кода:

- Объявление функции с параметрами и типом возвращаемого значения.
- Реализация расчёта в теле функции.
- Возвращение результата расчёта с помощью `return`.

```Go
// Функция для вычисления ИМТ возвращает результат с типом float64
func calculateIMT(userKg float64, userHeight float64) float64 {
```

## 4.7. Несколько значений возврата функции

Функция `getUserInput`, которая возвращает два значения: высоту и вес пользователя в килограммах.

### Шаги Реализации

1. Описание Функции:

   - Функция `getUserInput` не принимает на вход аргументов.
   - Возвращает два значения: высоту и вес пользователя в формате `float64`.

2. Возврат Нескольких Значений:
   В Go можно возвращать несколько значений из функции, указав их типы через запятую в скобках, например: `(float64, float64)`.

3. Реализация:

   - Переместить логику получения данных пользователя внутрь функции `getUserInput`.
   - Вернуть высоту и вес, используя `return userKg, userHeight`.

```Go
// Функция с двумя возвращаемыми параметрами (float64, float64)
func getUserInput() (float64, float64) {
	var userHeight float64 // обязательно указывается тип (по умолчанию 0.0)
	var userKg float64     // обязательно указывается тип (по умолчанию 0.0)
	fmt.Print("Введите свой рост в сантиментрах: ")

	// Результат ввода данных будет помещен в переменную userHeight
	fmt.Scan(&userHeight) // Используется указатель для передачи параметра
	fmt.Print("Введите свой вес: ")

	// Результат ввода данных будет помещен в переменную userKg
	fmt.Scan(&userKg) // Используется указатель для передачи параметра

	// Возврат из функции двух параметров
	return userKg, userHeight
}
```

4. Получение Значений из Функции:

   - Объявить переменные для хранения возвращаемых значений.
   - Вызвать `getUserInput` для получения высоты и веса.
   - Присвоить возвращаемые значения этим переменным.

```Go
	// Функция getUserInput() возвращает два параметра
	userKg, userHeight := getUserInput()

	// Используем функцию для вычисления ИМТ
	IMT := calculateIMT(userKg, userHeight)

	// Функция для вывода результата
	outputResult(IMT)
```

## 4.8. Scope функций

### Скоуп и именование переменных

- Скоуп (Scope): Область видимости внутри функции, определяемая ограничениями фигурных скобок. Все, что находится внутри этих скобок, учитывается при исполнении функции.
- Переменные и константы: Можно использовать различные имена для аргументов функции; они работают в пределах своего скоупа. Пример: переменная `CalculateIMT` может быть названа по-разному, это не повлияет на функционирование функции.
- Глобальный скоуп: Константы и переменные, определённые вне функции, доступны внутри функции. Например, константа, объявленная вне функции, используется в её теле.
- Вызов функций: Функции могут вызываться только в рамках других функций или `main`.

### Альтернативный синтаксис возврата

- Традиционно возвращаемое значение объявляется как тип данных (например, `float64`). Существует альтернативный способ, позволяющий сразу указывать переменную, которая будет хранить результат. Это упрощает синтаксис, позволяя опустить необходимость явного возвращения переменной.
- Вместо создания новой переменной для хранения результата, можно использовать уже существующую, изменяя её значение в процессе исполнения функции, и просто использовать `return` без указания переменной. Это сокращает код, но может ухудшить его читаемость, особенно при наличии нескольких возвращаемых значений.

```Go
// Обычный синтаксис возвращаемое значение float64
// Функция для вычисления ИМТ возвращает результат с типом float64
func calculateIMT(userKg float64, userHeight float64) float64 {
	const IMTPower = 2 // Константа для возведения в степень

   // := обозначает создание переменной и присваивание значения
	IMT := userKg / math.Pow(userHeight/100, IMTPower)
   // Обычный синтаксис требует указания имени переменной в return
	return IMT
}
```

Альтернативный синтаксис

```Go
// Альтернативный синтаксис возвращаемое значение (IMT float64)
// Функция для вычисления ИМТ возвращает результат с типом float64
func calculateIMT(userKg float64, userHeight float64) (IMT float64) {
	const IMTPower = 2 // Константа для возведения в степень

	// В альтернативном синтаксисе используется оператор =
   // = обозначает присваивание значения существующей переменной
	IMT = userKg / math.Pow(userHeight/100, IMTPower)
	// В альтернативном синтаксисе не указывается имя переменной в return
	return
}
```

## 5.1. Типы данных

Основные типы данных

1. Целочисленные типы (`int`)
   Основной тип: `int` используется для представления целых чисел без дробной части.
   Дополнительные типы:
   `int8`, `int16`, `int32`, `int64` позволяют работать с числами разной битности, оптимизируя использование памяти (например, `int8` подходит для чисел от `-128` до `127`).
   `uint8`, `uint16`, `uint32`, `uint64` (начинается с `u`) – это беззнаковые целочисленные типы, не поддерживающие отрицательные значения (например, `uint8` подходит для чисел от 0 до 255).

2. Вещественные типы
   `float32` и `float64`:
   `float32` поддерживает точность до 7 знаков после запятой.
   `float64` обеспечивает точность до 15 знаков после запятой и занимает в два раза больше памяти.

3. Строковый тип (`string`)
   Строки используются для работы с текстовыми данными.

4. Логический тип (`boolean`)
   Boolean (`bool`) принимает два значения: `true` или `false`. Этот тип используется для управления потоком выполнения программы, позволяя ей принимать решения.

```go
var data any = "hello"  // Может хранить любое значение
```

4. Псевдонимы типов (Type Aliases)

```go
type ID int       // Создает новый тип на основе int
type Text string  // Псевдоним с семантическим смыслом
```

Примеры использования:

```go
package main

import "fmt"

func main() {
    // Базовые типы
    var (
        age     int     = 30
        price   float64 = 19.99
        name    string  = "Alice"
        isAdmin bool    = true
    )

    // Составные типы
    ids := []int{1, 2, 3}                    // Срез
    user := struct{ Name string }{Name: "Bob"} // Анонимная структура
    var p *int = &age                         // Указатель

    fmt.Printf("%T: %v\n", age, age)      // int: 30
    fmt.Printf("%T: %v\n", ids, ids)      // []int: [1 2 3]
    fmt.Printf("%T: %v\n", user, user)    // struct { Name string }: {Bob}
    fmt.Printf("%T: %v\n", p, *p)         // *int: 30
}
```

Ключевые особенности:

- Статическая типизация — тип переменной определяется при компиляции.
- Нулевые значения — переменные без инициализации получают `значение по умолчанию` (например, 0 для int, "" для string).
- Строгая проверка типов — нельзя смешивать типы без явного преобразования.
- Для проверки типа во время выполнения используйте `reflect.TypeOf()` или `type assertions`:

```go
value := 42
fmt.Println(reflect.TypeOf(value))  // Выведет: int
```

## 5.2. if

Оператор `if` позволяет программе принимать решения, основанные на проверке условий (истинность или ложность).

Принимает условие (`boolean` выражение), и если условие истинно (`true`), выполняет код внутри блока.

### Пример применения:

Цель: На основе ИМТ (IMT) пользователей, интерпретировать значение и давать рекомендации.
Условие: Если ИМТ менее 16, необходимо сообщить пользователю о недостатке веса.

```Go
	if IMT < 16 {
		fmt.Println("У вас недостаток веса")
	}
```

В условии сравниваем ИМТ с числовым значением (16), результатом сравнения является `boolean` значение.
В примере предлагается создать переменную `isLean := IMT < 16` (худощавый), которая принимает значение результата сравнения (`IMT < 16`), для упрощения понимания.

### Варианты сравнения для boolean условий:

- Больше (`>`)
- Меньше (`<`)
- Больше либо равно (`>=`)
- Меньше либо равно (`<=`)
- Равно (`==`)

### Специфика оператора равенства:

- Два знака равенства (`==`) используются для проверки равенства.
- Отличие от одного знака равенства, который применяется для присвоения значения переменной.

## 5.3. Булева логика

Базовые операторы: И (`AND`), ИЛИ (`OR`), НЕ (`NOT`).

1: Оператор И (`AND`)
Истинность выражения достигается только если оба условия верны.

2: Оператор ИЛИ (`OR`)
Оператор дает истину, если хотя бы одно из условий истинно.

3: Оператор НЕ (`NOT`)
Преобразование истинного значения в ложное и наоборот.

## 5.4. else if

Условные операторами `if`, `else`, и `else if` на примере калькулятора индекса массы тела (ИМТ). ИМТ классифицируется в разные категории в зависимости от полученного числового значения. Чтобы определить категорию по ИМТ, применяем условные операторы, позволяющие сравнивать значение ИМТ с заранее определенными диапазонами значений и возвращать соответствующий результат.

1. Проверка первого условия:
   Если ИМТ меньше 16, выводим сообщение о сильном дефиците массы тела.

2. Использование `else`:
   `else` применяется для выполнения кода в случае, если предыдущее условие (`if`) не выполнилось.

3. Использование `else if` для дополнительных условий:

   - С применением `else if` проверяем ИМТ в других диапазонах, например, от 16 до 18,5 указывает на дефицит массы тела.
   - Для проверки нахождения ИМТ в заданном числовом диапазоне используем логический оператор "и" (`&&`).

4. Важность порядка условий:
   Приводим к упрощению кода, обращая внимание на порядок условий. Первым делом проверяем более специфичные случаи, затем – более общие. `else` выполняется, если не было удовлетворено ни одно из предыдущих условий.

```Go
	if IMT < 16 {
		fmt.Println("У вас сильный дефицит массы тела")
	} else if IMT < 18.5 {
		fmt.Println("У вас дефицит массы тела")
	} else if IMT < 25 {
		fmt.Println("У вас нормальный вес")
	} else if IMT < 30 {
		fmt.Println("У вас избыточный вес")
	} else {
		fmt.Println("У вас степень ожирения")
	}
```

## 5.5. switch

Проблема `if-else`: При большом количестве условий код становится трудночитаемым.

Решение: Конструкция `switch` предлагает более читаемый и упрощённый способ обработки множественных условий.

### Как работает switch:

1. `switch` проверяет значение переменной и сопоставляет его с предопределёнными случаями (`case`).
2. Каждый `case` определяет уникальную обработку для определённого значения переменной.
3. `default` используется для обработки всех непредвиденных значений.

### Пример использования:

1. Проверка переменной `IMT` на совпадение с различными `cases`: 1, 2, и т.д.
2. Каждый `case` выполняет уникальные действия для каждого значения `IMT`.
3. `default` обрабатывает случаи, не покрытые предыдущими `cases`.

```Go
	IMT = 2 // Для тестирования установим значение 2

	switch IMT {
	case 1:
		fmt.Println("IMT = 1")
	case 2:
		fmt.Println("IMT = 2")
	default:
		fmt.Println("Значение по умолчанию")
	}
```

### Преимущества switch:

1. Упрощает код при замене множественных `if-else` конструкций.
2. Улучшает читабельность кода.

### Расширенное использование switch:

1. Возможность использования без явного указания переменной путём прямого задания условий в `case`.
2. Эффективно используется для проверки диапазонов значений или комплексных условий.

```Go
	switch {
	case IMT < 16:
		fmt.Println("У вас сильный дефицит массы тела")
	case IMT < 18.5:
		fmt.Println("У вас дефицит массы тела")
	case IMT < 25:
		fmt.Println("У вас нормальный вес")
	case IMT < 30:
		fmt.Println("У вас избыточный вес")
	default:
		fmt.Println("У вас степень ожирения")
	}
```

## 5.6. Циклы

Циклы - элемент программирования, позволяющий повторять блок кода в зависимости от заданных условий.

### Цикл For в Go

`For` - это единственный вид цикла в Go, обладающий гибкостью и способный выступать в роли других типов циклов других языков программирования (например, `while`).

### Анатомия цикла For:

1. Инициализация:
   Декларация и инициализация переменной цикла (например, `i := 0`). Не обязательно объявлять вспомогательную переменную.

2. Условие:
   Условие продолжения цикла (цикл выполняется, пока условие истинно, например, `i < 10`).

3. Итерация:
   Инструкция изменения переменной цикла после каждой итерации (например, `i++`).

### Примеры использования:

1. Счетчик:
   Простой пример с использованием всех трех компонентов цикла, печатающий числа от 0 до 9.

```Go
	for i := 0; i < 10; i++ {
		fmt.Printf("%d\n", i)
	}
```

Равноценная допустимая запись (когда есть зависимость от внешней переменной):

```Go
	i := 0
	for i < 10 {
		fmt.Printf("%d\n", i)
		i++
	}
```

2. Вариации:
   Адаптация цикла под специфические задачи путем опускания компонентов инициализации и/или итерации.

3. Бесконечный цикл:
   Цикл без указания условия завершения, который может быть прерван изнутри цикла по специальному условию.

## 5.7. Break и continue

break и continue позволяют изменять поведение циклов в зависимости от выполнения определенных условий.

### Использование break

`break` прекращает выполнение цикла, независимо от его изначального условия.

Пример: Если в цикле, который должен выполниться 10 раз, мы встречаем условие, при котором переменная `i` равна 5, использование `break` немедленно прекратит цикл. Таким образом, цикл завершится на пятой итерации, не доходя до своего логического конца.

### Использование continue

`continue` прекращает текущую итерацию цикла и немедленно переходит к проверке условия для следующей итерации.

```Go
	for i := 0; i < 10; i++ {
		if i == 5 {
			break // Прервать выполнение цикла
		}
		fmt.Printf("%d\n", i)
	}
```

Пример: В том же цикле, если при переменной `i` равной 5 мы используем `continue`, текущая итерация прекратится, и цикл продолжится со следующей итерации. Это означает, что весь код после `continue` в текущей итерации не выполняется, но `цикл не прерывается полностью`, как в случае с `break`.

```Go
	for i := 0; i < 10; i++ {
		if i == 5 {
			continue // Пропустить текущую итерацию
		}
		fmt.Printf("%d\n", i)
	}
```

## 5.8. Повторение ввода

Реализация функционала, позволяющего пользователю проводить повторный расчёт ИМТ без перезапуска программы.

Шаги реализации:

1. Введение Бесконечного Цикла:

   - Программа оборачивается в бесконечный цикл для возможности повторения расчёта ИМТ.
   - Используется структура `for` без условий для создания бесконечного цикла.

2. Комментирование Кода:
   Для временного исключения кода из выполнения используется комбинация клавиш `Command + /` на MacOS или `Ctrl + /` на Windows.

3. Вывод Результата и Вопрос о Повторении:

   - После расчёта и вывода результата пользователю предлагается выбор - повторить расчёт ИМТ или завершить программу.
   - Ввод `Y` (да) приводит к повторению расчёта, любой другой ввод — к завершению работы программы.

4. Функция Проверки ввода Пользователя:

   - Создаётся отдельная функция для запроса у пользователя о желании провести повторный расчёт.
   - Ввод пользователем `Y` или `N` обрабатывается для определения необходимости повторения расчёта.

5. Условный Оператор и Логические Выражения:

   - Используется условный оператор `if` для проверки ответа пользователя.
   - Для обработки ввода регистронезависимо принимаются как заглавные, так и строчные буквы.

6. Прерывание бесконечного Цикла:
   Если пользователь выбирает не повторять расчёт, программа использует оператор `break` для выхода из бесконечного цикла и завершения работы.

```Go
func main() {

------------------------------
`)

		IMT := calculateIMT(userKg, userHeight)

	fmt.Println(result)
	switch {
```

## 5.9. Error

Обработка ошибок и крайних случаев в приложении, чтобы корректно реагировать на неверные вводы пользователя.

### Проблемы текущей реализации

- Приложение некорректно обрабатывает строки вместо чисел.
- Ввод нулевых или отрицательных значений ломает логику приложения.
- Отсутствует обработка этих сценариев.

### Обработка ошибок в Go

В Go ошибки обрабатываются иначе, чем во многих языках. Нет блока `try-catch` или оператора `throw`.
Ошибка возвращается из функции как значение, что упрощает работу с ней.
Нужно модифицировать функции, чтобы они возвращали не только результат, но и ошибку, если таковая случится.

### Пример: Функция с ошибкой

1. Модификация функции:

   - Добавление второго возвращаемого параметра типа `error`.
   - Проверка на неверный ввод (например, вес или рост <= 0) и возврат ошибки.
   - В случае успеха, возвращаем результат и `nil` вместо ошибки.

   `nil` - специальный тип в Go, который означает отсутствие чего-либо

2. Создание ошибки:
   Используем `errors.New("ТЕКСТ_ОШИБКИ")` для создания новой ошибки с описанием проблемы.

3. Обработка ошибки:

   - Проверяем, не вернула ли функция ошибку.
   - Если ошибки нет (`nil`), продолжаем выполнение.
   - Если ошибка есть, выводим сообщение и возможно предлагаем повторить попытку.

Пример кода:

```Go
package main

// Импорт нескольких пакетов
import (
	"errors"
	"fmt"
	"math"
)

func main() {
	fmt.Print(`
------------------------------
Калькулятор индекса массы тела
------------------------------
`)
	// Бесконечный цикл (с выходом по условию)
	for {
		// Функция getUserInput() возвращает два параметра
		userKg, userHeight := getUserInput()

		// Используем функцию для вычисления ИМТ
		IMT, err := calculateIMT(userKg, userHeight)

		// Если ошибку необходимо проигнорировать, используем _
		// IMT, _ := calculateIMT(userKg, userHeight)

		// err == nil означает отсутствие ошибки
      // err != nil есть ошибка
		if err != nil {
         // Блок обработки ошибки
			fmt.Println("Не заданы параментры для расчёта")
			continue // Повторить ввод
		}

		// Функция для вывода результата
		outputResult(IMT)

		isRepeateCalculation := checkRepeatCalculation()
		// Завершение цикла при условии !isRepeateCalculation
		if !isRepeateCalculation {
			break
		}
	}
}

// Функция для вычисления ИМТ возвращает результат float64 и ошибку
func calculateIMT(userKg float64, userHeight float64) (float64, error) {
	const IMTPower = 2 // Константа для возведения в степень

	// Проверка корректности данных, должны быть положительные значения
	if userKg <= 0 || userHeight <= 0 {
		// Возвращает 0 и ошибку
		return 0, errors.New("PARAMS_ERROR")
	}

	IMT := userKg / math.Pow(userHeight/100, IMTPower)
	// Возврат результата и отсутствие ошибки
	return IMT, nil
}
```

### Игнорирование ошибок:

- Использование нижнего подчеркивания `_` для игнорирования ошибки в случаях, когда её возникновение маловероятно.
- Не рекомендуется игнорировать ошибки, кроме особых случаев.

```Go
   // Если ошибку необходимо проигнорировать, используем _
   // _ нижнее подчеркивание означает игнорирование
   // _ может использоваться для любых параметров (не только ошибок)
   IMT, _ := calculateIMT(userKg, userHeight)
```

## 5.10. Panic

Паника является механизмом в программировании, позволяющим приложению завершить работу при обнаружении критической ошибки.

При вызове паники приложение завершается с кодом ошибки, отличным от нуля, что сигнализирует об ошибке.

### Когда Использовать Панику

1. Критические ошибки:
   Если программа сталкивается с ошибкой, после которой невозможно продолжить работу.

2. Невозможность обработки ошибки:
   В случаях, когда приложение не может корректно обработать ошибку или продолжить выполнение после её возникновения.

### Реализация

1.  Паника вызывается с помощью специального метода, принимающего строку с описанием ошибки.

2.  В случае некорректной работы, например, при передаче неверных параметров, вместо продолжения выполнения, приложение сразу завершается с показом ошибки.

3.  Паника также выводит дополнительную отладочную информацию, такую как место в коде, где была вызвана.

### Обработка Ошибок vs Паника

1. Обработка ошибок:
   Если ошибка не является критической и может быть обработана (например, временная недоступность сервиса), следует обрабатывать ошибку и продолжать выполнение.

2. Паника:
   Используется при обнаружении ошибок, которые делают дальнейшее выполнение приложения невозможным. В этом случае приложение завершается с кодом ошибки.

### Важность Правильного Кода Ошибки

При разработке консольных приложений, которые взаимодействуют с другими утилитами, важно корректно завершать работу с соответствующим кодом ошибки. Это позволяет внешним утилитам определить, произошла ли ошибка и каков её характер.

```Go
func main() {
   ...
	// Бесконечный цикл (с выходом по условию)
	for {
		// Функция getUserInput() возвращает два параметра
		userKg, userHeight := getUserInput()

		// Используем функцию для вычисления ИМТ
		IMT, err := calculateIMT(userKg, userHeight)

		// err != nil есть ошибка
		if err != nil {
         // Завершить выполнение
			panic("Не заданы параметры для расчёта")
		}

		// Функция для вывода результата
		outputResult(IMT)

		isRepeateCalculation := checkRepeatCalculation()
		// Завершение цикла при условии !isRepeateCalculation
		if !isRepeateCalculation {
			break
		}
	}
   ...
}
```

### Коды завершения приложения `exit status`:

В Linux и Unix-подобных системах приложения возвращают код завершения (`exit code`) при завершении работы. Этот код представляет собой целое число, которое указывает на успешное или неуспешное выполнение программы.

### Стандартные коды завершения:

- 0 — Успешное завершение (программа выполнилась без ошибок).
- 1–255 — Ошибка (конкретное значение зависит от программы).

Некоторые общепринятые коды (по соглашению):

```Text
Код	Описание
-----------------------------------------------------
0       Успешное завершение
1       Общая ошибка (Catch-all для неуказанных ошибок)
2       Неправильное использование встроенных команд (например, bash, sh)
126     Команда не может быть выполнена (например, нет прав на выполнение)
127     Команда не найдена
128     Некорректный аргумент для exit (только exit 128 и выше)
128 + N Завершение по сигналу N (например, 129 = SIGHUP, 137 = SIGKILL)
130     Завершение по SIGINT (Ctrl+C)
137     Процесс убит (SIGKILL)
143     Процесс завершён (SIGTERM)
255     Выход за пределы допустимого диапазона (коды должны быть 0–255)
```

### Как проверить код завершения?

После выполнения команды в терминале можно проверить код через `$?`:

```bash
ls /some/nonexistent/dir
echo $?  # Выведет 2 (ошибка)
```

### Особенности:

- Коды 128–255 обычно связаны с сигналами (128 + номер сигнала).
- Некоторые программы (например, grep) возвращают 1, если результат не найден (но это не ошибка выполнения).
- Если программа завершается из-за сигнала, код будет 128 + номер сигнала.

## 5.11. Recover

Recover используется для восстановления из Panic:
Если не использовать специальные способы восстановления, восстановление может также быть выполнено при помощи контейнеризации.

```Go
func main() {
	// Обработка выхода из паники
	// Некоторая функция, которая выполнится в конце завершения main()
	// defer - функция с отложенным выполнением
	// Неименная функция, которая должна будет сразу вызвана
	// т.е. мы откладываем defer выполнение функции сразу по завершении
	defer func() {
		// Восстановление приложения из паники
		r := recover()
		if r != nil {
			fmt.Println("Recover: ", r)
		}
	}()

   ...
}
```

### Как работает recover() в Go?

`recover()` — это встроенная функция в Go, которая позволяет "перехватить" панику (`panic`) и продолжить выполнение программы. Она работает только внутри отложенных функций (`defer`).

1. Основные принципы

- `panic` и `recover` — механизм обработки критических ошибок
- Когда происходит `panic()`, выполнение функции немедленно останавливается.
- Go начинает раскручивать стек вызовов (unwind the stack), выполняя все defer-функции.
- Если в одной из defer-функций есть `recover()`, паника останавливается, и программа продолжает работу.

`recover()` возвращает значение, переданное в `panic()`

```go
defer func() {
    if r := recover(); r != nil {
        fmt.Println("Recovered from panic:", r)
    }
}()
panic("something went wrong")
// Выведет: "Recovered from panic: something went wrong"
```

2. Когда `recover()` не сработает?

❌ `recover()` вне `defer`:
`recover()` должен быть вызван напрямую внутри defer-функции.

```go
func main() {
    if r := recover(); r != nil {  // Не сработает!
        fmt.Println("This will never print")
    }
    panic("test")
}
```

❌ recover() в другой горутине:
`recover()` не может поймать панику из другой горутины.

```go
go func() {
    defer func() {
        if r := recover(); r != nil {  // Перехватит панику только в этой горутине
            fmt.Println("Recovered in goroutine:", r)
        }
    }()
    panic("goroutine panic")
}()
```

❌ Критические ошибки (например, `SIGSEGV`)
Если произошла ошибка на уровне ОС (например, `segmentation fault`), `recover()` не поможет.

3. Примеры использования

Пример 1: Защита от паники в функции

```go
func safeDivide(a, b int) (result int, err error) {
    defer func() {
        if r := recover(); r != nil {
            err = fmt.Errorf("panic occurred: %v", r)
        }
    }()
    return a / b, nil  // Если b == 0, будет паника
}

func main() {
    res, err := safeDivide(10, 0)
    if err != nil {
        fmt.Println("Error:", err)
        // Выведет: "Error: panic occurred: runtime error: integer divide by zero"
    }
}
```

Пример 2: Восстановление после паники и продолжение работы

```go
func main() {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("Recovered:", r)
        }
    }()

    fmt.Println("Start")
    panic("oh no!")  // Вызовет панику
    fmt.Println("This will not print")  // Не выполнится
}
// Вывод:
// Start
// Recovered: oh no!
```

4. Как работает `recover()` под капотом?

Когда вызывается `panic()`, Go:

1. Останавливает текущую функцию.
2. Начинает выполнять все defer-функции в обратном порядке (`LIFO`).
3. Если в `defer` есть `recover()`, то:
   - Паника останавливается.
   - Программа продолжает работу с места, где был `defer`.
4. Если recover() не вызван, программа аварийно завершается с выводом стека.

### Вывод

1. `recover()` работает только внутри `defer`.
2. Он перехватывает только паники в текущей горутине.
3. Его используют для грациозной обработки критических ошибок без падения программы.

## 6.2. Работа с массивами

В Go нельзя объявить массив (array) без указания количества элементов, потому что размер массива является частью его типа.

Правильные варианты:
Массив с указанием размера:


```Go
// Это короткое объявление переменной с инициализацией пустыми значениями
```

## 6.3. Slice

Различие между массивами и слайсами:

- Массивы представляют собой последовательность однотипных значений с фиксированной длиной.
- Слайсы не имеют фиксированной длины и позволяют работать с подмножеством массива.

### Создание слайса из массива

Чтобы создать слайс, можно "вырезать" часть массива. Пример:

- Есть массив `[1, 2, 3, 4, 5]`
- Чтобы создать слайс, содержащий только `[2, 3, 4]`, используется синтаксис с квадратными скобками и двоеточием, указывая индекс начала и конца подмассива `[1:4]`, где левая граница включена, а правая - исключена.

### Синтаксис создания слайсов

`partial := transactions[1:4]` создаст слайс, включающий элементы с индексами 1 до 3 (4 не включается). Опционально можно опустить начальный и/или конечный индекс:

- [1:] – со второго элемента до конца массива.
- [:4] – сначала массива до четвертого элемента (не включительно).
- [:] – создает копию всего массива в виде слайса.

## 6.4. Length и Capacity (len и cap)

Различия между массивами и слайсами, их хранение и особенности работы с ними.

### Массивы

1. Определение:
   Массивы - это блоки последовательной памяти с фиксированным количеством элементов.

2. Копирование:
   При копировании массива создается полностью новый блок памяти, содержащий все элементы исходного массива. Это приводит к дублированию данных и занимает в два раза больше памяти.

3. Изменение данных:
   Изменение элемента в копии массива не оказывает влияния на исходный массив.

### Слайсы

1. Определение:
   Слайсы - это ссылки на сегменты массивов. Они позволяют работать с частью массива без его копирования.

2. Свойства:

   - `Length` (Длина):
     Актуальное количество элементов в слайсе.
   - `Capacity` (Вместимость): Максимальное количество элементов, которое слайс может содержать, основываясь на размере исходного массива. `Capacity` может быть больше, чем длина слайса, давая возможность роста.

3. Изменение данных:
   Изменение элемента в слайсе приведет к изменению этого элемента в исходном массиве, так как слайс является ссылкой.

4. Работа со слайсами:
   Можно создавать новые слайсы из существующих, менять их размеры в пределах своей `capacity`, что не приводит к копированию данных.

### Особенности

- Создание слайса влечёт накладные расходы лишь на хранение информации о срезе, а не на данные, которые уже существуют в массиве.
- Изменения, произведенные в слайсе, напрямую отражаются на массиве, с которым он связан. Это связано с тем, что слайс содержит ссылку на часть массива.

## Массив (array) vs Срез (slice)

### Массив `[n]T`

1. Фиксированный размер (длина — часть типа).
2. Пример: `var arr [5]int` — массив из 5 целых чисел.
3. Нельзя объявить без указания размера.

### Срез `[]T`

1. Динамический (может расти и уменьшаться).
2. Пример: `var slice []int` — срез без фиксированного размера.
3. Можно объявить без указания длины.

### Примеры:

❌ Ошибка: попытка объявить массив без размера

```go
var arr []int  // Это срез (slice), а не массив!
var arr [ ]int // Ошибка: синтаксис не поддерживается
```

✅ Правильные варианты:

Массив с указанием размера:

```go
var arr1 [3]int        // [0, 0, 0]
arr2 := [5]string{}    // ["", "", "", "", ""]
```

Срез (без фиксированного размера):

```go
var slice1 []int       // nil (пустой срез)
slice2 := []int{1, 2}  // [1, 2] (инициализированный срез)
```

### Как создать массив без явного указания размера?

Если необходимо, чтобы размер массива определялся автоматически при инициализации, можно использовать `[...]`:

```go
arr := [...]int{10, 20, 30}  // Компилятор сам посчитает длину (3)
fmt.Println(len(arr))        // 3
```

Но это работает только при инициализации, а не при объявлении переменной.

### Вывод:

- Массив `[n]T` требует указания размера.
- Если нужна динамическая длина — используйте срез `[]T`.
- `[...]T{...}` позволяет не указывать размер явно, но только при инициализации.

## 6.5. Динамические массивы - slice

В языке Go нет встроенных динамических массивов, но можно использовать слайсы для достижения аналогичного функционала. Слайсы используют массивы под капотом, но предоставляют гибкость в изменении размера.

### Объявление слайсов:

1. Слайс объявляется без уточнения размера, что позволяет не ограничивать его начальной длиной.
2. Слайсы могут изменять свою длину.
   Пример: слайс с тремя элементами, можно выводить на экран часть слайса, изменять элементы.

### Добавление элементов:

Для добавления элементов в слайс используется функция `append`.
Пример: добавление в слайс элемента 100.

```Go
transactionSlice = append(transactionSlice, 100) // append возвращает новый slice
```

`append` проверяет емкость слайса (`capacity`). Если емкости недостаточно для добавления элемента, `append` увеличивает емкость и добавляет элемент.

### Изменение и создание новых слайсов:

`append` может создать новый слайс если емкость исходного слайса недостаточна. Изменения в новом слайсе не отразятся на исходном.
Для модификации существующего слайса, результат append должен быть присвоен ему же.

### Другие операции со слайсами:

Удаление элементов из слайса возможно путем создания нового слайса через указание диапазона.

### Особенности работы со слайсами:

При использовании `append` и присвоении результата новой переменной, исходный слайс останется без изменений. Это важно учитывать при работе с данными.

```Go
package main

import (
	"fmt"
)

func main() {
	// Объявление массива из 3-элементов
	// В обоих случаях массив будет проинициализирован нулевыми значениями

	// Объявление переменной с явным указанием типа:
	// Все элементы массива инициализируются нулевыми значениями
	var transactionsA [3]int // [0 0 0] Работает везде (пакет/функция)

	// Это короткое объявление переменной с инициализацией пустыми значениями
	transactionsB := [3]int{} // [0 0 0] Работает только внутри функций

	// Инициализировать с предопределённым набором элементов
	transactions := [6]int{1, 2, 3, 4, 5, 6}
	banks := [2]string{"Тинькофф", "Альфа"}
	wallets := [2]string{} // Объявить как переменную без присвоения
	wallets[0] = "Черный"  // Записать определенный элемент по индексу

	fmt.Println(transactionsA)   // [0 0 0]
	fmt.Println(transactionsB)   // [0 0 0]
	fmt.Println(transactions)    // [1 2 3 4 5 6]
	fmt.Println(transactions[1]) // 2 Прочитать определенный элемент по индексу
	fmt.Println(banks)           // [Тинькофф Альфа]
	fmt.Println(wallets)         // [Черный ]

	copy := transactions            // Это полная независимая копия массива
	copy[1] = 100                   // Изменение не повлияет на исходный массив
	fmt.Println(transactions, copy) // [1 2 3 4 5 6] [1 100 3 4 5 6]

	// Slice
	patrial := transactions[1:] // Часть от 1 до последнего
	fmt.Println(patrial)        // [2 3 4 5 6]

	// Slice ссылается на исходный массив
	// Любое изменение slice приводит к изменению исходного массива
	transactionsPartial := transactions[1:5]          // slice от array
	fmt.Println(transactionsPartial)                  // [2 3 4 5]
	transactionsNewPartial := transactionsPartial[:1] // slice от slice
	fmt.Println(transactionsNewPartial)               // [2]
	transactionsNewPartial[0] = 30                    // изменит slice и array

	fmt.Println(len(transactionsNewPartial), cap(transactionsNewPartial))

	transactionsNewPartial = transactionsNewPartial[0:4] // это уже другой slice

	fmt.Println(transactions)           // [1 30 3 4 5 6]
	fmt.Println(transactionsNewPartial) // [30 3 4 5] часть массива transactions

	// Length (Длина): Актуальное количество элементов в слайсе.
	// Capacity (Вместимость): Максимальное количество элементов,
	// которое слайс может содержать, основываясь на размере исходного массива.

	fmt.Println(len(transactionsPartial), cap(transactionsPartial))       // 4 5
	fmt.Println(len(transactionsNewPartial), cap(transactionsNewPartial)) // 4 5

	// Динамическим может быть только slice
	// slice не имеет фиксированной длины изначально
	// Под капотом создается массив на который ссылается slice
	transactionSlice := []int{0, 20, 35}
	temp := transactionSlice
	// append() нельзя использовать для array, но можно использовать для slice
	transactionSlice = append(transactionSlice, 100) // append возвращает новый slice

	fmt.Println(temp)                 // [0 20 35] temp ссылается на другой массив
	fmt.Println(transactionSlice[1:]) // [20 35 100] новй slice без 0-го элемента
}
```
