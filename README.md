## 1.1. Почему Golang

### Цели курса

- Разобраться в основах языка Go.
- Научиться писать приложения, используя стандартную библиотеку и внешние пакеты.
- Освоить написание тестов и работу с ошибками.

### Преимущества Go:

- Простота и Читаемость: Идеален для новичков, минимализм в синтаксисе.
- Стандартная Библиотека: Широкий спектр инструментов "из коробки".
- Высокая Производительность: Компиляция в исполняемые файлы, отличная скорость.
- Экосистема и Поддержка: Богатая экосистема и поддержка сообществом.
- Кросс-платформенность: Поддержка всех основных ОС, легкость дистрибуции.
- Статическая Типизация и простое Управление Ошибками: Повышают надежность кода.
- Встроенные Инструменты: Отладка, форматирование, тестирование без сторонних инструментов.

### Использование Go на практике:

Go используется в компаниях Google, PayPal, Microsoft и Netflix.

## 2.2. Установка Golang

### Способы установки:

1. Скачивание установщика пакета

   - Перейти на официальный сайт Go `https://go.dev/`
   - Нажать "Download" и выбрать версию в зависимости от операционной системы:
     `Windows`: выбрать указанный пакет для Windows.
     `Mac с процессорами M1 и выше`: выбрать архив для архитектуры ARM.
     `Mac с более старой архитектурой`: выбрать соответствующий пакет.
     `Linux`: выбрать версию для Linux.
   - Запустить установщик и следовать инструкциям.

Переключение версий Go (стандартный без установки менеджеров пакетов)

```shell
go install # (для управления версиями без WSL)
```

Способ установки нескольких версий:

```shell powershell
# Установка Go 1.21.0
go install golang.org/dl/go1.21.0@latest
go1.21.0 download
```

Плюсы:
✅ Официальный метод, не требует менеджеров.
✅ Можно иметь несколько версий.

Минусы:
❌ Нужно вручную вызывать go1.21.0 вместо go.
❌ Нет автоматического переключения.

Подходит, если:
🔹 Не хотите ставить Chocolatey/Scoop.
🔹 Готовы управлять версиями вручную.

2. Использование пакетного менеджера (Homebrew для macOS и Linux, Choco для Windows)

- Преимущество: удобное обновление.
- Homebrew устанавливается через терминал с помощью одного скрипта.
- Установка Go: `brew install go`.

3. Менеджеры версий `asdf-vm.com` или `goenv`

goenv и asdf это два популярных менеджера управления пакетами, самый популярный goenv.
На Windows нужно использовать WSL, нет нативного варианта.
WSL + goenv/asdf если вы используете WSL2:

Пример установки goenv:

```bash
# Установка goenv (специально для Go)
git clone https://github.com/syndbg/goenv.git ~/.goenv
echo 'export GOENV_ROOT="$HOME/.goenv"' >> ~/.bashrc
echo 'export PATH="$GOENV_ROOT/bin:$PATH"' >> ~/.bashrc
echo 'eval "$(goenv init -)"' >> ~/.bashrc
source ~/.bashrc

# Установка Go
goenv install 1.21.0
goenv global 1.21.0
```

Плюсы:
✅ Полная поддержка версий (как в Linux).
✅ Автоматическое переключение в проектах.

Минусы:
❌ Требует WSL (не чистая Windows).

Подходит, если:
🔹 Вы работаете с WSL (например, для Docker, Kubernetes).
🔹 Нужны сложные сценарии с разными версиями Go.

4. Chocolatey (Choco) — Windows

```shell powershell
choco install golang
```

Плюсы:
✅ Быстрая установка одной командой.
✅ Легко обновлять (choco upgrade golang).
✅ Можно установить конкретную версию (через -version).

Минусы:
❌ Нет удобного переключения между версиями (как в goenv/asdf).
❌ Зависит от Chocolatey (не всем нравится).

5. Scoop — альтернатива Chocolatey с поддержкой версий

```shell powershell
scoop install go
# Или конкретная версия
scoop install go@1.21.0
scoop reset go@1.21.0  # Переключение
```

Плюсы:
✅ Легко переключать версии (`scoop reset go@версия`).
✅ Не требует админ-прав (устанавливает в `~/scoop`).

Минусы:
❌ Меньше версий, чем в `goenv/asdf`.

Подходит, если:
🔹 Хотите что-то проще Chocolatey.
🔹 Нужно переключать версии, но без WSL.

### Проверка установки

Запустить команду `go` в терминале. Если видим справку по командам Go, установка прошла успешно.

### Обновление Go

- Важно использовать версию 1.22 и выше для последних функций HTTP роутинга в Go.
- Проверка текущей версии: `go version`.
- При необходимости обновления: повторно запустить установку через пакетный менеджер.

https://go.dev/
https://brew.sh/

## 2.3. Установка Scoop на Windows

Scoop — менеджер пакетов для Windows, который устанавливает программы без прав администратора (в папку пользователя).

1. Предварительные требования
   Windows 10/11 (или Windows 7+ с PowerShell 5.1+).

PowerShell 5+ (проверьте версию):

```shell powershell
$PSVersionTable.PSVersion
```

Если версия ниже 5.0, обновите PowerShell.

2. Установка Scoop

🔹 1. Откройте PowerShell (от имени пользователя, не админа!)
Нажмите Win + X → Windows PowerShell (или Terminal).

🔹 2. Разрешите выполнение скриптов

```shell powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

(Ответьте Y на запрос).

🔹 3. Установите Scoop

```shell powershell
irm get.scoop.sh | iex
```

🔹 4. Проверьте установку

```shell powershell
scoop --version
```

Должна отобразиться версия (например, 7.3.2).

3. Настройка Scoop (опционально)

🔸 Добавление репозиториев (бакетов)
Scoop использует "бакеты" (коллекции пакетов). Основные:

```shell powershell
scoop bucket add main      # Основные программы (по умолчанию)
scoop bucket add extras    # Доп. ПО (например, Notepad++)
scoop bucket add versions  # Версионные пакеты (Node.js, Go и др.)
```

🔸 Обновление Scoop

```shell powershell
scoop update
```

4. Установка Go через Scoop

```shell powershell
scoop install go           # Последняя версия
# Или конкретная версия:
scoop install go@1.21.0
scoop reset go@1.21.0      # Переключение версий
```
